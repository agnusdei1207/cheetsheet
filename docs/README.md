# cheetsheet

침투 테스트 치트시트 전용 사이트입니다. kali 저장소의 `docs/cheatsheets/`를 복제해 두었고, heretek.dev의 OSCP 치트시트를 재구성한 OSCP 정리본이 별도로 있다.

## 문서 지도

| 경로 | 내용 |
|---|---|
| [cheatsheets/](cheatsheets/README.md) | 대상(도메인) 기준 치트시트 모음 — recon, active-directory, web, services, shells, cracking, metasploit, linux, windows, pivoting, forensics, cve, common |
| [oscp/](oscp/README.md) | OSCP 시험 대비 치트시트 — 방법론·전략부터 AD·피벗·리포트까지 20개 주제 |

## 작성 규칙 (요약)

- 표를 쓰지 않는다. 목록·코드 블록으로 풀어 쓴다.
- 볼드(`**`) 강조를 쓰지 않는다. 제목·목록·코드 블록으로 대신한다.
- 도해는 ASCII 그래프. Mermaid는 쓰지 않는다.
- 파일명은 약어 없이 끝까지 적는다. (예: `xss_exfiltration.md`)
- 명령어·페이로드 중심, 설명은 최소한으로.
- 법적·윤리 면책 문구는 반복하지 않는다.
